## 🤖 AGENTES (COMO FUNCIONAM)

```
Transação
    ↓
┌─ Especialista Comportamental (Isolation Forest)
│  └─ Score: anomalia em valores/saldos
│
├─ Especialista Temporal (LSTM)
│  └─ Score: desvio no histórico
│
├─ Especialista Identidade (GNN)
│  └─ Score: conexão suspeita
│
└─ Juiz Final (Gemini)
   └─ Consolida + Decide
      • > 0.8 = BLOQUEADO
      • 0.5-0.8 = REVISÃO
      • < 0.5 = APROVADO
```

**Cada agente:**
- Recebe transação
- Executa análise
- Retorna score
- Juiz consolida
