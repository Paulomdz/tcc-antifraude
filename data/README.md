# Pasta de Dados

Coloque aqui o dataset PaySim baixado do Kaggle:

**Arquivo esperado:** `PS_20174392719_1491204439457_log.csv`

**Link para download:** https://www.kaggle.com/datasets/ealaxi/paysim1

Após colocar o arquivo, execute:
```bash
python src/preprocessing/load_paysim.py
```

Isso irá gerar o arquivo `paysim_processed.parquet` com os dados pré-processados.
