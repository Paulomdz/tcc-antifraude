Decisões
- D2: a API preserva o step recebido. A função compartilhada de features aplica
  o módulo 24 antes da normalização; limitar a entrada a 0..23 seria
  incompatível com steps do dataset.
- D7: sem GOOGLE_API_KEY, /analise_transacao mantém o 503 com
  {"detail": "Gemini não configurado. Defina GOOGLE_API_KEY no .env."};
  lote e histórico continuam disponíveis sem chave.
- D8: lote chama orchestrate_ml_only (fast). Production continua na análise
  individual; deep permanece somente função de orquestração.
- D13: o pacote neste repositório é src/orquestacao/. O import da API aponta
  para src/orquestacao/fluxo_multiagente.py.
- Serviço: usado o nome oficial escolhido pelo usuário, sem inventar uma nova
  marca.
